2. NumPy 中的前向传播
def dense(a_in, W, b, g):
    units = W.shape[1]
    a_out = np.zeros(units)
    for j in range(units):
        z = np.dot(W[:, j], a_in) + b[j]
        a_out[j] = g(z)
    return a_out
在编写 numpy 数组 W 时，你会把每个神经元的 W 参数放在哪里？
（ ）放在 W 的行中。
（✓）放在 W 的列中。
✓ 正确 神经元 1 的 W 参数在第 1 列，神经元 2 的参数在第 2 列……
