3. NumPy 中的前向传播
def dense(a_in, W, b, g):
    units = W.shape[1]
    a_out = np.zeros(units)
    for j in range(units):
        z = np.dot(W[:, j], a_in) + b[j]
        a_out[j] = g(z)
    return a_out
对于上面定义单个神经元层的 “dense” 函数代码，for 循环会执行多少次？注意 W 有 2 行 3 列。
（ ）2 次
（ ）6 次
（✓）3 次
（ ）5 次
✓ 正确 层中每个神经元对应 numpy 数组 W 中的一列；W 的每一行表示有多少个输入特征进入该层。for 循环为每个神经元计算激活值。所以如果 W 有 5 列，该 dense 层就有 5 个神经元，for 循环就会执行 5 次迭代（每个神经元一次）。
