3. 逻辑回归：损失 = −y·log(a1) − (1 − y)·log(1 − a1)；J(w,b) = 损失的平均值
Softmax 回归的代价：
a1 = e^z1/(e^z1 + e^z2 + … + e^zN)，…，aN = e^zN/(e^z1 + e^z2 + … + e^zN)
loss(a1, …, aN, y) = −log a1 若 y = 1；−log a2 若 y = 2；…；−log aN 若 y = N
对于多类别分类，训练模型时使用交叉熵损失。如果输出有 4 个可能的类别，而某个训练样本的真实类别是第 3 类（y = 3），那么交叉熵损失简化为？（提示：当 a3 变大时，该损失应当变小。）
（ ）−log(a1) − log(a2) − log(a3) − log(a4)
（✓）−log(a3)
（ ）z3
（ ）e^z3/(e^z1 + e^z2 + e^z3 + e^z4)
✓ 正确 当真实类别为 3 时，该训练样本的交叉熵损失就是 softmax 第 3 个神经元激活值的负对数。交叉熵损失公式中其他所有项（−log(a1)、−log(a2)、−log(a4)）都被忽略。
得分 1/1
