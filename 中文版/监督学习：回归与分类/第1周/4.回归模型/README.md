# 实验 1：
在这个不计分实验中，你将看到线性回归模型是如何用代码定义的，并看到一些图表：在给定不同的 w 和 b 取值时，模型对数据的拟合程度如何。你还可以尝试不同的 w 和 b 取值，看看是否能改善对数据的拟合。


# 实验 2
这个选做实验将向你展示代价函数是如何用代码实现的。给定一个小型训练集和不同的参数取值，你将能够看到代价如何随模型对数据的拟合程度而变化。

在这个选做实验中，你还可以操作一个交互式等高线图。你可以用鼠标光标点击等高线图上的任意位置，图中会显示出由你所选参数 w 和 b 确定的那条直线。

最后，这个选做实验还提供了一个三维曲面图，你可以用鼠标光标手动旋转、翻转它，从而更好地观察代价函数的样子。
